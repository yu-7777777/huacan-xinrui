Reference detail implementation

Implemented: fine paper grain and brocade; fret border and corner ornaments; pan-chang knot separators; curved multilayer paper window; original-reference-style expanded book; painted mountain-cloud-reed artwork; perspective wooden type blocks; framed two-voice card and export corner ornaments; guide seal avatars, speech tails, quote frames, working copy actions and related-page navigation.

Built-in image tool used for two project assets (alpha preserved, converted to WebP only):
- frontend/assets/book-reference.webp: extract the broad open book and miniature town from approved home reference; retain bridge, red pavilion, trees, mountains, curled page and layers; remove all UI and text.
- frontend/assets/landscape-detail.webp: match approved typhoon header/footer; misty blue-gray ridges, thin cloud ribbons, reeds on right, transparent upper-left, no UI or words.

All other ornaments are native SVG/CSS so their dimensions stay responsive. Generated assets are interpretations of reference artwork, not pixel-identical source layers.
